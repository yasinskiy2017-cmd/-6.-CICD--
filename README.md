# Node.js CI/CD Project (GitHub Actions + AWS EC2)

Готовий проєкт для практичного заняття №6 з автоматичним розгортанням на хмарний сервер Amazon EC2.

## Структура проєкту
- `index.js` — вебсервер на базі Express.
- `test.js` — автоматичний тест для перевірки застосунку на етапі CI.
- `package.json` — конфігурація проєкту та залежностей.
- `.github/workflows/ci.yml` — пайплайн GitHub Actions (тестування + деплой по SSH через rsync та PM2).

## Інструкція із запуску
1. Створіть новий репозиторій на GitHub та завантажте туди всі файли з цього архіву (включно з прихованою папкою `.github`).
2. Запустіть інстанс EC2 (Ubuntu 20.04, `t2.micro`) з відкритим 22 портом у Security Group (та портом 3000, якщо хочете відкрити сайт у браузері).
3. У репозиторії GitHub перейдіть у **Settings -> Secrets and variables -> Actions** та додайте 3 секрети:
   - `EC2_HOST` — публічна IP-адреса вашого EC2.
   - `EC2_USER` — `ubuntu`.
   - `EC2_SSH_KEY_B64` — вміст вашого `.pem` ключа, закодований в один рядок (`cat devops-key.pem | base64 -w 0`).
4. Зробіть `git push` у гілку `main` — GitHub Actions автоматично протестує та задеплоїть застосунок на сервер.
